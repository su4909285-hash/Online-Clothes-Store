Online Clothes Store

A full-stack e-commerce web application for online clothing shopping.

Features

- User Authentication
- Product Browsing
- Shopping Cart
- Order Management
- Admin Dashboard
- Responsive Design

Technologies Used

- React.js
- Node.js
- Express.js
- Supabase
- JavaScript
- Tailwind CSS

Installation

npm install
npm run dev
